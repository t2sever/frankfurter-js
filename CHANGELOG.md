# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and this project aims to follow Semantic Versioning.

## [0.1.0] - 2026-03-20

### Added

- Initial release of `frankfurter-js`.
- TypeScript client for the Frankfurter currency API (v2).
- Support for rates, latest, historical, range, currencies, and providers endpoints.
- ESM and CommonJS builds with bundled type declarations.
- Community health files: contributing guide, issue templates, pull request template, and Dependabot configuration.
